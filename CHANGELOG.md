# Changelog

All notable changes to this fork are listed here. Versions follow [semantic versioning](https://semver.org):
`vMAJOR.MINOR.PATCH`, one git tag per version. haprod is a fork of
[Daryl](https://rickub.com/hlassiege/daryl) by Hugo Lassiège; "upstream" below means Daryl.

## v0.2.0 (2026-11-16)

First version of the fork, based on upstream commit `89fef88` (package version 0.1.0).

### macOS

- Runs on macOS: native file and folder dialogs (AppleScript), reveal in Finder, Chrome lookup,
  Homebrew paths for ffmpeg, npx and Claude Code, system fonts for on-screen texts.
- The fal.ai key is read from the macOS Keychain (Windows keeps the user environment).
- `ffmpeg-full` is preferred when installed, with a clear message when the `drawtext` filter is missing.

### Performance on Apple Silicon

- Whisper runs on the GPU through mlx-whisper, cut at silences in chunks of 30 s at most, with a filter
  for text invented on background noise.
- Video is encoded by VideoToolbox (`STUDIO_ENCODER=x264` goes back to libx264).

### Claude and ChatGPT

- Connect and disconnect the Claude account from Settings; same for ChatGPT (Codex).
- Choose the Claude model, separately for light steps and heavy steps.
- Every Claude turn of a project step is logged with its usage in `data/claude-usage.jsonl`.
- Thumbnails without fal.ai: generated by ChatGPT (subscription), or composed by Claude from your images.

### Fixes

- `httpx` was missing from the requirements (the worker crashed on start).
- PyAV is kept below 19, which breaks faster-whisper 1.2.
