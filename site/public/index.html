A tour of Daryl

A studio on your machine, an assistant that asks first

Your files stay with you
Projects, footage and renders live in a folder on your disk. Whisper, ffmpeg and the renderer run locally.
Runs on your Claude Code plan
Daryl drives Claude Code with your subscription. No API key to set up, no second bill.
Nothing changes without you
Cuts, titles, beats and edits are suggestions. They land in your project when you accept them.

Editing jobs for Claude Code

Some jobs work better from a Claude Code session opened in the repository. Daryl ships them as skills.

  • /music-bedScores the edit: one track per sequence, cut to cover it and ducked under the voice.
  • /replace-aroll-takeSwaps a stretch of A-roll for a re-recorded take and moves everything on top of it.
  • /snatch-cutProposes a burst of close-ups with snap zooms and punchy sounds, with a preview.

A personal tool, shared as is

I make every video of my channel with Daryl. I share it because people asked to see it, not to sell anything: there is no course, no paid plan, no waiting list.

It follows how I work and evolves in that direction. It is built for one person on Windows, and maintained on a best-effort basis. Fork it, take what you need, or use it for ideas.

Try it

You need Windows, Python 3.12, Node.js with pnpm, ffmpeg and Claude Code logged in.

git clone https://rickub.com/hlassiege/daryl.git
cd daryl
py -3.12 -m venv .venv
.venv\Scripts\pip install -r backend\requirements.txt
cd web; pnpm install; pnpm build; cd ..\backend
..\.venv\Scripts\python -m studio

Then open http://localhost:4400. Read the README for the optional services: cloud transcription, thumbnails, YouTube upload, music.
